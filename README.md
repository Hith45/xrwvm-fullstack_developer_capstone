# Cars Dealership Capstone Project

A full-stack web application for a national car retailer in the United States.

The application allows users to:
- View dealership locations and details.
- Browse car makes and models.
- Register, log in, and log out.
- Read and submit dealership reviews.
- Analyze review sentiment.

## Technologies
- Frontend: React
- Backend: Django and Python
- Database: MongoDB
- Deployment: Docker, Kubernetes, and IBM Cloud Code Engine
- CI/CD: GitHub Actions# coding-project-template
